# Privacy

IP Scanner performs network discovery locally on the user's device.

Depending on the platform and enabled features, the application may
process:

- Local IP addresses
- Hostnames
- Open TCP ports
- Bonjour service names
- NetBIOS names
- MAC addresses on macOS
- Manufacturer information derived from MAC address prefixes

IP Scanner does not transmit scan results or network information to
the developer.

Export files are created only when initiated by the user.

The application does not include advertising, analytics, tracking, or
telemetry unless explicitly documented in a future release.
